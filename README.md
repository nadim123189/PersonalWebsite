# Charging Ahead, but for Whom?

A one-page site with three visualizations of public EV charging in Massachusetts, from our DS4200 group project.

- **Open it:** double-click `index.html`. It needs an internet connection to load the Vega charting libraries.
- **Rebuild the data:** run `python scripts/build_data.py` (needs pandas). It reads `data/source/` and writes `data/site-data.js`.
