# Charging Ahead, but for Whom?

A two-page site on public EV charging in Massachusetts, from our DS4200 group project.

- `index.html`: home page with the project introduction and contact links.
- `visualizations.html`: three charts. The growth chart and map use Vega-Lite, and the network chart uses D3.
- **Open it:** double-click `index.html`. It needs an internet connection to load the fonts and charting libraries.
- **Rebuild the data:** run `python scripts/build_data.py` (needs pandas). It reads `data/source/` and writes `data/site-data.js`.
- **Photos:** both are by 4300streetcar on Wikimedia Commons, licensed CC BY 4.0, and credited on the page.
